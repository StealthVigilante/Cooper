Addressable systems

Know the room, not just the zone.

Every device on an addressable system reports its own name and location. If a motion sensor trips in a school, the monitoring station knows which classroom. If a smoke sensor activates, firefighters know where to go.

Questions

Commercial questions, answered.

It depends on the situation. Some applications call for commercial grade equipment. A display running most of the day, seven days a week, has to be a commercial model: a consumer TV will not last, and commercial use usually voids its warranty.

Code sets the minimum for your building's size and use, and your local fire official enforces it. We design to that requirement and tell you plainly what is required and what is optional, so you are not paying for devices you do not need.

Start with a survey. We review your existing panel and devices against the current requirements for your building, then set out what needs to change before inspection.

Panels and locks keep running on battery backup within its capacity. Beyond that, each door is set to fail safe or fail secure according to its role, so exit paths release while storage and server rooms stay locked.
